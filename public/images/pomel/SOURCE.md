# Pomel Figma assets

Source: https://www.figma.com/design/ptKpIAgtz1X0Wc8DRPD7Dq/?node-id=722-4570
Frame: Frame 460
Exported: 2026-09-10

The 13 child frames were downloaded using their configured PDF export settings, then converted to SVG with vector text outlines and embedded original images. No Figma layers were modified. Assets are stored locally so the website does not depend on temporary Figma URLs. Source PDF files are in tmp/figma for verification.

Project 1 uses these SVG sections in PomelPortfolio.tsx, with lazy loading below the first section. Its thumbnail remains 05.png. Raster photos retain their source resolution; text and vector artwork scale sharply.
